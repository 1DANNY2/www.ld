# DJLangels — Normal HTML Structure

This version separates the website into three simple files:

- `index.html` — website content and structure
- `style.css` — colors, sizes, layout, backgrounds and appearance
- `script.js` — menu, modal, active navigation and forms

## Easy editing

Change visible words in `index.html`.

Examples:
- `<h1>...</h1>` = main heading
- `<h2>...</h2>` = section heading
- `<p>...</p>` = paragraph
- `<img src="...">` = image
- `<video controls>...</video>` = video
- `<a href="...">...</a>` = link

Change colors, spacing and sizes in `style.css`.
Change interactive behavior in `script.js`.

The original design and functionality are retained; the main improvement is that CSS and JavaScript are no longer hidden inside `index.html`.
